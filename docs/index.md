# Innesto documentation

Innesto is an independent project for writing native mods for Openworld.
Each supported game version has its own development branch for the loader and
API.

## Compatibility

| Openworld | Platform | Innesto status |
| --- | --- | --- |
| a1.2.10 | Linux x86-64 | Initial development target |

The [first release milestone](https://github.com/ImJstNickDev/Innesto/milestone/1)
tracks native mod initialization, mod discovery and a cancellable block-break
event. Installation instructions will accompany the first tested release.

## Contribute

- [Development guide](development.md) for setting up the docs, choosing a branch and submitting changes.
- [API conventions](api-conventions.md) for designing, documenting and testing an API that several mods can use together.
