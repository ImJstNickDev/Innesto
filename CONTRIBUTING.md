# Contributing to Innesto

Start with the [development guide](docs/development.md) for branch selection,
the local check and the pull request workflow. For a change to the modder-facing
API, use the [API conventions](docs/api-conventions.md).

Use GitHub Issues for reproducible bugs and proposals. Include the Innesto
revision, game version, platform, expected result and observed result. Share
only original Innesto examples and sanitized output. Keep game distribution
metadata, fingerprints, binaries, symbols and private integration notes out of
commits, issue reports, pull requests, CI logs and attachments.
